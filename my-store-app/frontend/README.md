# Frontend — UniPOS

Giao diện React 19 + Vite + Tailwind CSS. Hướng dẫn cài đặt, chạy, kiểm thử và triển khai đầy đủ
nằm trong [README ở thư mục gốc](../../README.md).

```bash
npm install
npm run dev     # http://localhost:5173 — tự proxy /api sang backend :8080
npm run lint
npm run build   # xuất ra dist/ (được đóng gói vào image Nginx bằng Dockerfile)
```
